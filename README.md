# CyberPet: Red Core

Eine **eigene** virtuelle Haustier-App im Cyberpunk-/Roboter-Stil. Sie verwendet keine originalen Pou-Dateien, Grafiken oder Spielstände.

## Bereits eingebaut
- 999.999.999 Münzen und Level 100
- Essen, Sauberkeit, Schlaf und Laune
- MAX-Modus: alle Werte bleiben dauerhaft bei 100 %
- Normalmodus: Werte sinken langsam und können wieder aufgefüllt werden
- Räume: Küche, Bad, Hauptraum, Schlafzimmer, Draußen
- Pet antippen: je nach Raum füttern, reinigen, schlafen oder Laune steigern
- Kühlschrank und Cyber-Shop
- 3 kostenlose Skins: Chrome, Stealth, Gold
- Sound-Schalter
- Erfolge
- Minispiel „Red Core Tap“
- automatischer lokaler Spielstand
- eigene Android-Canvas-Grafik ohne fremde Spielassets

## APK bauen
Das Projekt enthält einen GitHub-Actions-Workflow unter `.github/workflows/build-apk.yml`. Nach einem Push auf `main` baut GitHub automatisch eine Debug-APK als Artifact.

## Hinweis
Das ist ein eigenständiges CyberPet-Konzept und **keine modifizierte Pou-APK**.
